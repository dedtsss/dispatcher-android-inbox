# Визуальный контракт Catching: кандидат 0.6.9

Основание: физические замечания владельца от 10.11.2026 в PR #8. Реализация остаётся Kotlin / Jetpack Compose / Material3. Принципы UI UX Pro Max применяются к контрасту, семантическим цветам, плотности, состояниям и навигации. CRM Vega Slate не является утверждённой темой Catching. Этот контракт и Android-снимки представляют кандидат для приёмки на телефоне.

- Поверхности: графит `#121318`, `#191A20`, `#24252C`; обычный текст `#ECECEF`, вторичный `#B7B7C0`. Глубокий фиолетовый `#705C8A` применяется к заливке активного действия, светлый `#F4F0F8` — к его содержимому. Текст и иконки на графите используют светлые семантические цвета, а не тёмный акцент.
- Главный экран: исходная композиция кот + Catching по центру, ширина до 208 dp, пропорциональный Fit. Буквы получают светлый семантический цвет через существующую маску; исходная альфа, рисунок кота и фиолетовая точка сохраняются. Отдельной белой плашки нет.
- Панель ассистента: только голова исходного кота, строго по центру заголовка. Область нажатия 48 dp; X слева и настройки справа имеют независимые области не менее 48 dp. Надписи Catching в панели нет. Касание кота открывает приложение, X закрывает панель, шестерёнка открывает настройки.
- Логотип: неизменённый `catching_logo.png`, 890×210, SHA-256 `a9296b9822071d87a0fd105dfa3a574a11713ada58df28f5256b31a28a03ce5f`. Голова занимает x≤237; буквы начинаются x≥261. Отображение головы ограничивает область до x=250 в прозрачном зазоре; форма и пропорции кота не меняются. Нового рисунка или ресурса нет.
- Кнопки и состояния: спокойные нейтральные подписи, единые Material3 отступы. Ошибка остаётся отличимой; отключённое управление сохраняет стандартное состояние Material3. Нижняя вкладка возвращает к существующему экрану записи, повторное нажатие не создаёт новый экран.
- Панель закрывается после подтверждённого локального commit текста/голоса/файла. Сетевой статус и Drive не задерживают возврат. При ошибке сохранения панель и черновик остаются; полноэкранное приложение после сохранения остаётся открытым.

Расчёт WCAG для заданных пар: основной текст/поверхность 14,72:1, вторичный/вариант поверхности 7,67:1, содержимое кнопки/акцент 5,20:1, содержимое/контейнер акцента 9,54:1. Это проверка цветов, а не подмена проверки реального Android-рендеринга.

Проверка: Actions Android — прозрачность и исходные пиксели кота, нормальная/узкая ширина, доступность X/настроек, центрирование, снимки главного экрана/панели/очереди/настроек, переходы и lifecycle. Физическая оценка владельцем обязательна до переключения updater.
