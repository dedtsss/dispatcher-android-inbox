## Полезная правка 0.6.6/code12

Исходный Logo.png — RGBA 890×210, SHA-256 `a9296b9822071d87a0fd105dfa3a574a11713ada58df28f5256b31a28a03ce5f`, побайтно совпадает с `/home/codex/approved-assets/catching/Logo.png`. 105172 пикселя полностью прозрачны; отдельной белой подложки нет. Кот x5..237/y4..200, буквы x261..889/y34..183, фиолетовая точка x682..717/y25..60. Между котом и буквами прозрачный зазор. Маски привязаны к этому проверенному ресурсу.

Удалён `.background(Color.White)`. CatchingLogoPainter рисует три непересекающиеся области прежнего Painter: кот в исходных цветах, буквы тем же альфа-контуром со светлым цветом onSurface, точка в исходном фиолетовом. Никаких новых шрифтов/котиков, генерации или изменения PNG. Fit, ограничения 208/184dp, отступы и работа X/шестерёнки/ввода/сохранения сохранены. Room/очередь/оригиналы/package/ключ не меняются.

Новая Android-регрессия рендерит оригинал и адаптацию, сравнивает альфа-канал каждого пикселя, точные цвета кота/точки и светлый цвет пикселей букв с alpha≥128 (в исходнике нет alpha=255 у букв). В прежний тест двух экранов/двух ширин добавлен пиксельный контроль отсутствия светлой плашки; геометрия и площадь кнопок продолжают проверяться. Предусмотрен install-over опубликованной 0.6.5 с проверкой её хеша/сертификата, включая повтор после restart.

На момент preflight активные artifacts занимают **272468900 Б** при прежнем пределе **280000000 Б**; для нового release artifact (~29 МБ без сжатия) места нет. **BLOCKED_CI_ARTIFACT** для доставки APK. Лимит PR #9 не повышается, исторические/чужие доказательства не удаляются. Один CI запускается ради полезной проверки изменённого UI и девяти Android-тестов; добавлен компактный архив только PNG/XML/отчётов (≤3 МиБ), также за прежним бюджетом. Без полного зелёного CI и точного артефакта нельзя публиковать новый APK/переключать updater. Выпуск 0.6.5 и публичный manifest сохраняются. Для дальнейшей доставки нужно освободить место по согласованной политике хранения, затем получить точный готовый артефакт; локальная пересборка запрещена.

Результаты CI и снимки будут дописаны по факту. PR #8 не объединять до физической и Google OAuth приёмки.

## Первый прогон и доказательное уточнение теста

[CI 42449144133](https://github.com/dedtsss/dispatcher-android-inbox/actions/runs/42449144133), source `82dd0ec1751dfec6566d99922f1cb9574063d326`: unit/lint/build и семь install-over, включая опубликованную 0.6.5, прошли. Android 8/9: новый тест не проверил буквы, потому что ошибочно выбирал только alpha=255. Аудит исходного PNG подтвердил **0** таких пикселей у букв, 34124 с alpha≥128; самые частые alpha 251/252/250. Попиксельные проверки неизменности альфа-канала и кота/точки прошли, но проверка цвета без выбранных пикселей закономерно остановила набор; restart ещё не запускался.

Артефакт `оформление-0.6.6` 13605211198, digest `fdbbe26b1a66467d82b85f2b73dbf258573bd6311c03726936b106036cc8efdf`. Снимки скачаны и просмотрены: на обеих ширинах плашки нет, надпись светлая, кот и точка сохранены, кнопки свободны. Статусы отправки на этих синтетических снимках — результаты тестовых фикстур; это не реальный Google Drive E2E.

Исправляется только тест: проверять цвет более 30000 пикселей alpha≥128 с допуском RGB ±2 для округления premultiplied alpha; проверка точного совпадения альфа-канала каждого пикселя и цветов кота/точки остаётся строгой. Код приложения/версия не меняются. Один повтор после установленной причины ошибки теста; APK и updater не публикуются.
