Предварительная версия для физической проверки владельцем: главный экран «Записать» по утверждённому макету «Запись в центре».

Крупный центральный микрофон, мягкий фиолетовый ореол, история реальных уровней под кнопкой, крупные «Текст / Файл» в одном ряду. Исходный прозрачный логотип сохранён. На малой высоте композиция уменьшается; при вводе текста освобождается место клавиатуре. Нижние вкладки переключаются без длительной анимации.

Версия0.6.11/code17, package `ru.bruce.dispatcherinbox`. Устанавливать поверх0.6.9 или0.6.10 без удаления приложения. Локальные оригиналы, очередь и настройки сохраняются. Прежний постоянный signer; APK берётся из точного проверенного CI без пересборки.

Проверить на телефоне: сохранность прежних записей/настроек; вид главного экрана; тихую/обычную/громкую речь и паузы; stop→локальное сохранение→очередь; работу без сети и последующую отправку в Drive; текст/файл/Back/повторное открытие; прежнее auto-close системного ассистента. Динамика индикатора требует физической оценки; эмулятор не подтверждает акустическую чувствительность и наличие оригиналов в реальном Drive.

Встроенный обновлятор остаётся на0.6.9, PR #8 не объединён. Эта версия не означает физическую приёмку владельцем.
