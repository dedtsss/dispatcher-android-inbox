# Приёмник — Dispatcher Android Inbox

Минимальное Android-приложение для быстрого приёма текста, голоса и файлов с локальной очередью и последующей отправкой в серверный Диспетчер. Телефон ничего не классифицирует и не запускает AI: он только надёжно сохраняет ввод и синхронизирует его.

## Что входит в MVP

- главный экран без ленты: текст, голос, файл/фото и одна кнопка сохранения;
- запись AAC/M4A через `MediaRecorder` с тихими системными сигналами старта/остановки;
- импорт файлов через системный picker во внутреннее app-specific storage;
- приём `ACTION_SEND` и `ACTION_SEND_MULTIPLE` для текста и файлов;
- Room-очередь со статусами `draft`, `queued`, `syncing`, `synced`, `error`;
- WorkManager-синхронизация с ограничением по сети или Wi-Fi и backoff;
- multipart API: JSON-part `payload` и один или несколько `files[]`;
- настройки URL, Bearer token и поведения синхронизации в DataStore;
- debug-заглушка: при пустом API URL debug-сборка не выходит в сеть и помечает запись отправленной с `debug-...` remote ID;
- заготовка системного ассистента и запрос `ROLE_ASSISTANT`, если роль доступна;
- launcher shortcut «Быстрая заметка»;
- unit-тесты фабрики записей, статусов, payload и fake-синхронизации.

## Что не входит

Категории, проекты, выбор агентов или моделей, AI/распознавание речи на телефоне, постоянное прослушивание, Accessibility, аналитика, Firebase и сложная серверная история обработки намеренно отсутствуют.

## Сборка

Требуются JDK 17+ и Android SDK Platform 36. Gradle отдельно устанавливать не нужно — wrapper включён в репозиторий.

```bash
./gradlew testDebugUnitTest assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions выполняет те же тесты и сборку на каждый `push` и `pull_request`, затем публикует APK как artifact `dispatcher-inbox-debug-apk`.

## Установка

Подключите телефон с включённой USB-отладкой и выполните:

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Либо передайте APK на устройство, разрешите установку из выбранного источника и откройте файл. При первой записи голоса Android запросит доступ к микрофону.

## Подключение Диспетчера

1. Откройте вкладку «Настройки».
2. Укажите базовый URL, например `https://dispatcher.example/`.
3. Введите Device/Bearer token. Токен не встроен в APK и не выводится в Logcat.
4. Настройте автосинхронизацию, Wi-Fi-only и удаление файлов после успешной отправки.

Запрос отправляется на `POST /api/mobile-inbox/items` с `Authorization: Bearer <token>`. HTTP разрешён только в debug-сборке для локальной разработки; release требует HTTPS на уровне Android network security. Если URL задан, а token отсутствует, сетевой запрос не выполняется и запись получает понятную ошибку настройки.

## Проверка сценариев

### Обычный ввод

Введите текст и нажмите «Сохранить». Без сети запись останется в очереди; WorkManager дождётся подходящей сети. В debug-сборке с пустым URL сработает локальная заглушка.

### Голос

Нажмите микрофон, разрешите доступ, продиктуйте заметку и нажмите кнопку остановки. После второго сигнала запись сохраняется и сразу ставится в очередь. Распознавания речи нет.

### Share target

В другом приложении выберите текст, фото, видео, PDF или файл → «Поделиться» → «Приёмник». Для нескольких файлов используйте приложение, которое отправляет `ACTION_SEND_MULTIPLE`. Копирование выполняется не в UI-потоке; исходный временный URI больше не нужен после завершения экрана подтверждения.

### Системный ассистент

Откройте «Настройки» → «Сделать приложением-ассистентом». На Android 10+ приложение запрашивает `ROLE_ASSISTANT`; если производитель устройства не предоставляет роль, откроются системные настройки голосового ввода/приложений по умолчанию. Реализован безопасный `VoiceInteractionService` stub, который открывает экран голосового ввода, но системные оболочки могут не показывать сторонний сервис или ограничивать запуск с заблокированного экрана.

## Ограничения Android и MVP

- фоновые задачи запускаются по расписанию Android, а не мгновенно; Doze и ограничения производителя могут добавить задержку;
- `ROLE_ASSISTANT` зависит от версии Android и прошивки;
- большие файлы занимают место во внутреннем хранилище до успешной отправки или ручного удаления;
- при включённом «Удалять файлы после отправки» метаданные записи остаются в Room, а локальные вложения удаляются;
- token хранится в DataStore приложения, но MVP не добавляет аппаратное шифрование; следующим этапом стоит подключить Android Keystore;
- удаление из очереди сейчас выполняется сразу, без корзины;
- release-сборка с пустым URL не использует fake API и показывает ошибку настройки.
