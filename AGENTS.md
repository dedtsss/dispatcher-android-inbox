# Инструкции исполнителям

## Обязательный язык публикаций GitHub

**Весь новый авторский человекочитаемый текст, публикуемый в GitHub от имени владельца, писать по-русски.** Это относится к названиям и описаниям задач, запросам на слияние, комментариям и отзывам, этапам и результатам исполнения, сообщениям коммитов, отчётам, журналам, документации и авторским пояснениям в коде. Перед публикацией проверять язык и исправлять английские шаблонные фразы. Не переводить программные идентификаторы, имена и пути, команды, параметры, API, машинные статусы (`RUN_STARTED`, `SUCCESS`, `BLOCKED` и др.), код и дословные внешние цитаты, если перевод нарушает точность или совместимость. Исключения — только по явному указанию владельца либо при строгой технической необходимости. Исторические записи массово не переписывать. Общее обязательное правило: [политика русского языка](https://github.com/dedtsss/agent-dispatch/blob/main/docs/memory/github-russian-language-policy.md).



## Строгий запрет локальных сборок Android

На VPS **запрещено** запускать Gradle/Flutter/Kotlin/SDK/NDK сборки, эмуляторы и компиляционные проверки без отдельного **предварительного разрешения владельца на конкретную сборку**. Запрет относится также к CatVPS (DevCat), BrainVPS, BruceVPS, Office-PC, терминалам Codex/Hermes и всем подчинённым исполнителям. Не обходить отказ или недоступность GitHub Actions запуском `./gradlew` на сервере, включая проверку `assembleDebug` или `test`. Не считать прошлые локальные испытания разрешением на новые.

Если штатный GitHub Actions временно недоступен по оплате/квоте/иным причинам, выполни только безопасные проверки без компиляции, зафиксируй `BLOCKED_CI`, доступные альтернативные внешние сборщики и запроси согласие владельца. Если он разрешил один конкретный локальный запуск, необходимо сначала проверить подходящий узел и применить **ограничения ОС** на память, подкачку, ЦП, количество процессов и время; без доказанной изоляции компиляцию не запускать.

Единственный полный нормативный регламент, включая запреты, условия исключения и проверку — [`dedtsss/agent-dispatch/docs/task-rules.md`, §7](https://github.com/dedtsss/agent-dispatch/blob/main/docs/task-rules.md). Локальная инструкция не заменяет его.
